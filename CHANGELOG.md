# Changelog

All notable NanoForge changes are documented here.

## [1.0.4] - 2026-08-29

### Added

- Resizable and collapsible desktop navigation and model catalog sidebars.
- Persisted panel widths and visibility preferences, with a reset layout action.
- App-wide right-click menu for creating chats, opening folders, managing panels, and copying the active file path.
- Clearer artifact dock navigation, copy/download controls, and empty-state guidance.

### Packaging

- Refreshed Windows executable, installer, and portable release bundles.
- Standalone launcher bundles now include the sidecar files required for direct execution.
